# ttms

TTMS 相关 Skill 与配套工作目录的仓库根目录。

当前正式纳入版本管理的核心内容位于：

- `qa-test-case-generator/`

其中包含：
- `SKILL.md`
- `references/`
- `templates/`
- `scripts/`
- `evals/`

运行时和评估阶段产生的工作目录保留在仓库根下，但默认不纳入版本管理：

- `qa-test-case-generator-workspace/`

## 仓库结构

```text
ttms/
├── README.md
├── .gitignore
├── qa-test-case-generator/
└── qa-test-case-generator-workspace/
```
